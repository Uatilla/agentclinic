# Claude Code skills

A skill is a saved prompt the agent can run as `/<name>`. Create one with the skill creator.

## Where they live
- Personal: `~/.claude/skills/<name>/SKILL.md`, available in every project.
- Project: `.claude/skills/<name>/SKILL.md`, committed with the repo.

## Rules
- The source prompt lives in the guide it belongs to (e.g. SDD templates in `prompts.md`);
  edit it there, then regenerate the skill.
